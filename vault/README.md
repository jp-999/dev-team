# Knowledge vault (Obsidian-structured)

This `vault/` is the team's durable memory, structured as an **Obsidian vault** — plain Markdown
with `[[wikilinks]]`, `#tags`, backlinks, and a graph. It's local-first and lock-in-free (same
plain files the agents already read).

## Use it
- **With Obsidian:** *File → Open folder as vault* → point at this `vault/`. You get backlinks,
  tag search, and the interactive graph for free.
- **Without Obsidian:** `python3 scripts/vault_graph.py` generates `Backlinks.md` and `graph.json`
  from the links/tags, so agents (and you) can still navigate the knowledge graph.

## What's here
- `Home.md`, `Roles.md`, `Chapters.md`, `Upskilling.md` — maps of content (committed seeds).
- `improvements/` — one note per adopted improvement, written automatically by the 12-hour
  upskilling cycle (`scripts/upskill.py`). Generated; not committed.
- `graph.json`, `Backlinks.md` — generated by `scripts/vault_graph.py`. Not committed.
